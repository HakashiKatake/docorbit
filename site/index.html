Root-Cause Engineering

The 5 Hallucination Vectors Solved

AI coding agents fail not because LLMs lack reasoning, but because the documentation they ingest is stale, collides with installed dependency versions, or lacks structured schemas.

Version Collisions

An agent in a Next.js 14 project gets fed Next.js 15 documentation and uses await params, breaking your build. DocOrbit reconciles your installed lockfiles against documentation branches with SemVer laddering.

8 Ecosystems: npm, cargo, go, pypi, composer, rubygems, pub, maven

Escaped JSON & Bloat

Generic tools wrap documentation in stringified JSON schemas with escaped newlines and duplicate fields, wasting 50%+ of your token budget. DocOrbit returns clean, unescaped GitHub Markdown by default.

Saves 50–60% tokens per retrieval; optional format: 'json'

Missing API Contracts

Agents guess query params and body types because raw HTML docs lack typed contracts. DocOrbit indexes OpenAPI 3.x and Swagger 2.0 specs with safe circular $ref resolution and exact response models.

find_api tool returns paths, query params, auth, and response schemas

Stale Endpoints & Traps

Agents call deprecated APIs (e.g. Stripe /v1/charges instead of PaymentIntents) because docs omit gotchas. DocOrbit indexes breaking changes, server-only vs client boundaries, and 429 rate limit traps.

find_pitfall extracts explicit warnings, deprecations, and runtime traps

Prompt Injections & SSRF

Scraping unvalidated web pages lets adversaries inject malicious prompt instructions or attack cloud metadata endpoints (169.254.169.254). DocOrbit enforces SSRF guards and tags all content with untrusted provenance.

RFC 1918/4193 blocklist, cloud metadata guard, untrusted: true metadata

Zero-Leak Local Storage

Unlike cloud scrapers that lock your code to external APIs, DocOrbit stores all documentation inside your project's local .docorbit/ directory. Deleting a project removes its documentation cache cleanly.

Zero orphaned files, zero disk leaks, offline-first SQLite FTS5 in WAL mode

Complete Agent Interface

15 Agent-Native MCP Tools

Designed specifically for AI coding workflows. Each tool delivers token-budgeted, evidence-grounded Markdown to give your agent the exact context it needs with zero hallucination.

get_implementation_context Core Loop

High-level orchestrator: scans project dependencies, resolves versions, packs relevant chunks, APIs, examples, and pitfalls within a strict token budget. Supports auto-ingestion from URL.

ingest_doc Loop Starter

Crawls and indexes documentation from any URL or raw markdown text directly into local SQLite, with instant task-focused blueprint synthesis.

check_api AST Verifier

Evaluates generated code against indexed OpenAPI schemas, parameters, required body fields, and version contracts without calling an LLM.

find_api Knowledge

Inspects OpenAPI endpoints with parameters, JSON request/response models, query parameters, bearer auth, and pagination cursor schemas.

find_example Knowledge

Discovers verified code examples filtered by framework (Next, Express, FastAPI, Django, Gin), programming language, and task.

find_pitfall Knowledge

Finds deprecations, breaking changes, server-only restrictions, and 429 rate limit traps before writing code.

find_recipe Knowledge

Assembles evidence-grounded implementation blueprints with explicit evidence levels (documented facts vs inferred steps).

diff_docs Change Intel

Compares documentation versions and snapshots to detect added, removed, modified, and deprecated endpoints.

analyze_impact Change Intel

Scans workspace repository files against documentation diffs, locating affected files, lines, snippets, and breaking certainty.

search_docs Retrieval

Sub-millisecond hybrid FTS5 search across documentation chunks with version boosting and title breadcrumbs.

get_doc Retrieval

Retrieves an exact documentation chunk or complete page by ID or URL with untrusted provenance boundaries.

get_version Retrieval

Reconciles workspace dependencies using the hierarchical SemVer confidence ladder (exact → major → range).

list_sources Retrieval

Lists indexed documentation sources, snapshots, page counts, and machine-readability status.

get_documentation_map Structure

Retrieves the hierarchical documentation tree, section headings, and token footprints for full navigation overview.

export_agent_context Export

Generates deterministic agent files (AGENTS.md, CLAUDE.md, skill.md, llms.txt, docs-map.md) grounded in dependency versions.

System Design

How DocOrbit Works

An end-to-end pipeline from autonomous discovery to closed-loop verification, running locally in Node.js 24 with zero external dependencies.

01
Autonomous Discovery
Probes llms-full.txt, OpenAPI 3.x, llms.txt, sitemaps, and crawls nested HTML category trees.
02
Semantic AST Slicing
Preserves section heading hierarchies, breadcrumbs, and indivisible code blocks without naive character splitting.
03
Version Intelligence
Scans workspace manifests across 8 ecosystems and locks exact documentation versions via deterministic docs.lock.
04
High-Speed FTS5
Persists to project-local SQLite with WAL mode, prepared statement cache, and 64MB memory page caching (~1.3ms).
05
15-Tool MCP Server
Delivers pure Markdown by default over stdio and Streamable HTTP, eliminating 50-60% token overhead.
06
Closed-Loop Verification
check_api AST verifier validates generated code against indexed contracts without calling LLMs.
