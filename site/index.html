PRACTICAL AGENT WORKFLOW

How to Work with DocOrbit

DocOrbit runs silently inside Cursor, Claude, Windsurf, or custom agents. You don't need to manually read 50 pages of docs or paste massive text files. Give your agent the task and the documentation link — DocOrbit automates tree crawling, AST slicing, and contract verification in milliseconds.

STEP 01

Mount the MCP Server

Add DocOrbit to your harness config once (.cursor/mcp.json, Claude Desktop, Windsurf, or Roo Code). Zero external dependencies, local SQLite engine.

npx -y docorbit mcp
STEP 02

Prompt Your Agent with Docs

Mention the documentation URL or library name in your regular prompt and tell your agent to use DocOrbit for grounding and verification.

"The link of docs: https://... Use docorbit to set it up."
STEP 03

Zero-Hallucination Execution

The agent calls ingest_doc, get_implementation_context, and check_api to generate 100% build-passing, contract-verified code.

✔ AST Verified • 0 Deprecated Calls • 1.4ms SQLite

import Stripe from 'stripe';

const stripe = new Stripe(process.env.STRIPE_SECRET_KEY!, {
  apiVersion: '2024-12-18.acacia',
});

export async function POST(req: Request) {
  const { items } = await req.json();

  // DocOrbit AST verified: stripe.checkout.sessions.create parameters
  const session = await stripe.checkout.sessions.create({
    payment_method_types: ['card'],
    line_items: items.map((item: any) => ({
      price: item.priceId,
      quantity: item.quantity,
    })),
    mode: 'payment',
    success_url: `${process.env.NEXT_PUBLIC_URL}/success?session_id={CHECKOUT_SESSION_ID}`,
    cancel_url: `${process.env.NEXT_PUBLIC_URL}/canceled`,
  });

  return NextResponse.json({ url: session.url });
}

15 Agent-Native MCP Tools

search_docs retrieval

search_docs(query, docVersion?, library?, limit?)
get_doc retrieval

Retrieve a complete normalized document or specific section chunk by URL or ID.

get_doc(url?, chunkId?, library?, docVersion?)
find_api retrieval

Structured OpenAPI & Swagger search with exact parameters, methods, and schemas.

find_api(endpoint?, method?, query?, library?)
find_example retrieval

Find verified code snippets filtered by programming language, framework, or task.

find_example(task?, language?, framework?)
find_pitfall retrieval

Search explicit breaking changes, deprecation warnings, and runtime gotchas.

find_pitfall(task?, kind?, library?)

Verify generated API calls against indexed documentation contracts via AST parsing.

check_api(endpoint, method?, code?, docVersion?)
diff_docs verification

Compare two documentation versions to identify added, removed, or changed APIs.

diff_docs(fromVersion, toVersion, sourceId?)
analyze_impact verification

Scan project workspace source code against deprecated APIs between versions.

analyze_impact(fromVersion, toVersion, projectDir?)

ingest_doc discovery

Fetch, normalize, slice, and index external documentation from URL or raw markdown.

get_docs_map(library?, docVersion?)
get_version discovery

Inspect project workspace dependencies and resolve authoritative doc versions.
